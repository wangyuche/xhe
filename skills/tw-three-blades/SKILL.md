# tw-three-blades

需求來源：Telegram 群組「股票分析」群主 fjjagur（2026-11-27），指定用刀神原書的做法。
做法依《海期刀神教你用100張圖實戰均線三刀流》《海期刀神的60分K獲利術》公開的書介與試閱內容整理；書中沒有公開的細節（斜率根數、停損停利點位）不自行補，只列可確認的判斷。
演算法寫死在腳本裡，**不要自己重算，一律呼叫腳本**。

## 一鍵執行

```bash
bash ~/.claude/skills/tw-three-blades/scripts/run.sh [代號] [輸出目錄]
```

- 代號預設 `IX0001`（加權指數）；個股直接給代號，例如 `2330`。輸出目錄預設 `~/.claude/tg/work`。
- 資料：`~/.claude/tg/fugle.sh` 抓 60 分 K 歷史約 180 天（240MA 需要 240 根 ≈ 48 個交易日）＋今天盤中（`combine.py` 合併）。歷史 K 抓不到就報錯結束、不沿用舊檔；交易時間盤中 K 抓不到或是空的時 stderr 印「警告」（空的也可能是今天休市），回覆要註明可能缺今天盤中。
- 輸出文字＋ `blades_<代號>_60m.svg`（最近約 15 個交易日的 60 分 K、三條均線、藍綠交叉標記、KD）。轉圖：

```bash
qlmanage -t -s 1200 -o ~/.claude/tg/work ~/.claude/tg/work/blades_IX0001_60m.svg
```

（qlmanage 要單獨一行指令，不能接 cd／管線／重新導向）

## 判斷內容（`scripts/three_blades.py`）

| 項目 | 內容 |
|---|---|
| 三條均線 | 60 分 K 簡單移動平均：小藍 20MA、小綠 60MA、小橘 240MA；各列數值、價格在上／下方與差距、斜率正負、最近一次價格站上或跌破的時間 |
| 排列 | 小藍 > 小綠 > 小橘 = 多頭排列；小藍 < 小綠 < 小橘 = 空頭排列；其他 = 糾結 |
| ① 方向 | 小橘斜率為正 = 多方環境；為負 = 空方環境（切忌積極做多）；剛好為 0 = 走平、方向不明（結論不判多空）；另列價格在小橘之上／之下與小橘斜率最近一次翻轉時間 |
| ② 藍綠交叉 | 最近一次小藍上穿小綠（黃金交叉）或下穿（死亡交叉）的時間（小藍−小綠的正負號真的翻轉才算，碰到又彈回不算）、價位、KD；目前 KD 是 K>D 轉強或 K<D 轉弱 |
| ③ 雙斜率 | 小藍、小綠斜率是否與小橘同方向 |
| ④ 不逆勢 | 價格是否站上三條線；沒有全部站上時列出壓在上方的線 |
| 結論 | 小橘向上＋藍綠黃金交叉＋KD 轉強＋價格站上三線 = 偏多（書中做多條件）；小橘向下＋藍綠死亡交叉＋價格在三線之下 = 偏空；小橘向下時出現黃金交叉 = 逆勢反彈、不積極做多；其餘列「條件未齊」與缺的每一項;小橘走平時不判多空 |

- 斜率 = 這根 MA 減 `--slope-n` 根前的 MA（預設 5 根 ≈ 1 個交易日），只看正負。書中沒寫根數，這是暫定值。
- KD(9,3,3)：RSV 9 根；K = 2/3 前 K + 1/3 RSV；D = 2/3 前 D + 1/3 K；初值 50。
- 盤中最後一根還沒走完時，標題列加「⚠️ 最後一根還沒走完」。

單獨呼叫：

```bash
python3 -I scripts/three_blades.py <60分K.json> [--asof "YYYY-MM-DD HH:MM"] [--slope-n 5] [--svg out.svg] [--title 名稱]
```

## 回覆格式

照腳本輸出逐行列出（三條均線、排列、①～④、結論），先發圖再發文字。結尾加「僅供參考，非投資建議」。不給下單、部位或停損停利建議（書中沒有公開具體數值）。
