# tw-bottom-signal

需求來源:Telegram 群組「股票分析」成員 Gg,2026-11-16;群主 fjjagur 同意做成 skill。
演算法寫死在腳本裡,**不要自己重算,一律呼叫腳本**,讓每次結果一致。

## 一鍵執行

```bash
bash ~/.claude/skills/tw-bottom-signal/scripts/run.sh [代號] [輸出目錄]
```

- 代號預設 `IX0001`(加權指數);個股直接給代號,例如 `2330`。
- 輸出目錄預設 `~/.claude/tg/work`。
- 資料:`~/.claude/tg/fugle.sh historical/candles/<代號>?timeframe=30|60`,抓最近 45 天(含當日盤中)。
- 每個週期印出 4 個訊號的「有 ✅ / 沒有 ❌」與點位,最後一行 `HITS n/4`;n ≥ 1 時另輸出 `bottom_<代號>_<30|60>m.svg`。

有 SVG 才轉圖(qlmanage 要單獨一行指令,不能接 cd / 管線 / 重新導向):

```bash
qlmanage -t -s 1200 -o ~/.claude/tg/work ~/.claude/tg/work/bottom_IX0001_60m.svg
```

產出 `….svg.png`,用 `send_photo.sh` 發送。**4 個訊號都沒有就不畫圖,只回文字。**

## 訊號定義(`scripts/bottom_signal.py`)

| # | 訊號 | 判斷 |
|---|---|---|
| — | KD(9,3,3) | RSV 取 9 根;K = 2/3 前 K + 1/3 RSV;D = 2/3 前 D + 1/3 K;初值 50 |
| — | 波段高低點 | 該根是前後各 3 根中的最高/最低;**右邊 3 根走完才算確認**(不偷看未來) |
| 1 | D 值底部背離 | 相鄰兩個確認低點 a → b:價格 L[b] < L[a] 且 D[b] > D[a] |
| 2 | 黃金交叉 | K 由下往上穿越 D,且交叉那根 D ≥ dmin(預設 20,`--dmin` 可改) |
| 3 | 突破下降壓力線 | 當下已確認的最近兩個波段高點,後高 < 前高,連線延伸;收盤由線下站上線上 |
| 4 | 突破 20MA | 收盤由 MA20(收盤價 20 根簡單平均)下方站上上方 |

「有出現」= 最近 `--lookback` 根(預設 10)內發生過。

單獨呼叫:

```bash
python3 -I scripts/bottom_signal.py <candles.json> 60分K [--asof "YYYY-MM-DD HH:MM"] [--lookback N] [--dmin N] [--svg out.svg] [--title 名稱]
```

`--asof` 可回測歷史某個時間點(範例圖用 `--asof "2026-11-10 10:00" --lookback 20`)。

## 圖

正方形 SVG(900×900、viewBox 1200),最近 60 根:上方 K 棒(紅漲綠跌)+ MA20 + 紫色下降壓力線,下方 K、D 線與 20 虛線。訊號用編號圓章標在突破點:① 綠 背離(價格與 D 值各一條虛線)② 藍 黃金交叉 ③ 紫 突破壓力線(▼)④ 紅 突破 20MA,左下圖例寫出時間與點位。

## 回覆格式

30 分 K、60 分 K 各列 4 行「有 ✅ / 沒有 ❌ + 點位」,最後總結 n/8 與最可能先出現的訊號;有圖先發圖再發文字。結尾加「僅供參考,非投資建議」。
