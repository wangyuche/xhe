# 規則表

每條規則成對記錄「規則」與「由什麼強制」。強制方式由強到弱:結構 > 檢查 > 測試 > 僅文字。
「僅文字」的規則若錯誤再發生,視為重複,下次要升級成更高層的強制方式。
規則對應的錯誤已經不可能發生時,移除該規則。
