# web-dev-kit 規格(skill,frontend-owner 與 backend-owner 共用)

固定腳本,避免每次即興寫而留下孤兒程序、截到空白頁、或誤判範圍。所有輸出放 `${WEB_DEV_KIT_TMP:-$TMPDIR/web-dev-kit}/<name>/`,不寫進專案。`<name>` 是任務名稱(小寫英文加連字號),由派工簡報給,沒給就用 `<agent>-<專案名>`,`<專案名>` = 專案根目錄(worktree 目錄)的 basename,轉小寫,非 `[a-z0-9-]` 的字元換成 `-`。平行派工時主 agent 必須給每個 worker 唯一的 `<name>`(例如含分支名)。

## 腳本介面

| 腳本 | 用法 | 輸出 / 結束碼 |
|---|---|---|
| `serve.sh` | `serve.sh <name> <dir> <起始埠> [--health <路徑>] [--timeout <秒>] [--env K=V]... -- <指令...>` | 從起始埠往上找第一個可用埠(最多 20 個);指令中的 `{port}` 會被替換,也會設 `PORT=<埠>`;同名服務已在執行時直接結束碼 1(不覆蓋);在 `<dir>` 以**新的程序群組**背景執行,log 到 `<tmp>/<name>/server.log`;輪詢 `http://127.0.0.1:<埠><health>`(預設 `/`)直到回應狀態 < 500,逾時預設 90 秒。成功:stdout `url=http://localhost:<埠> port=<埠> pgid=<n> log=<路徑>`,結束碼 0。指令提早結束或逾時:印 log 最後 30 行,停掉程序群組,結束碼 1 |
| `stop.sh` | `stop.sh <name>` | 對程序群組送 TERM,5 秒後仍在就 KILL;確認埠已釋放。stdout `stopped port=<埠>`,結束碼 0;埠仍被占用則結束碼 1。沒有在執行的同名服務:`not-running`,結束碼 0 |
| `shot.mjs` | `node shot.mjs <url> <寬> <高> <輸出.png> [--mobile] [--cookie name=value]... [--cookie-jar <檔>] [--header 'K: V']...` | `--cookie` 與 `--cookie-jar`(唯讀,curl `-c` 產生的 Netscape 格式;`#HttpOnly_` 開頭的行去掉前綴後當 cookie,其他 `#` 開頭的行才是註解)逐筆以 `Network.setCookie` 設在 url 的網域,`--header` 以 `Network.setExtraHTTPHeaders` 設定(用於要登入的頁面)。 只用 Node 22 內建 `fetch` / `WebSocket`,不依賴 npm 套件。啟動 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome --headless=new --remote-debugging-port=0`,`--user-data-dir` 每次用 `mktemp -d` 建立;結束時(含失敗、逾時)關閉 Chrome 並刪除該目錄。先 `fetch` 確認 HTTP 狀態;viewport 用 `Emulation.setDeviceMetricsOverride`:桌面 `{width:<寬>,height:<高>,deviceScaleFactor:1,mobile:false}`,`--mobile` 為 `{width:<寬>,height:<高>,deviceScaleFactor:3,mobile:true}` 加 `setTouchEmulationEnabled`。導覽後等 load + 網路閒置 500 ms(上限 15 秒),**先量** `scrollWidth`、`innerWidth`、`pageHeight`,再截整頁(`captureBeyondViewport`)。收集 `Runtime.exceptionThrown` 與 console `error`。stdout 一行 JSON(寬高皆為 CSS px):`{"http":200,"width":1280,"height":800,"scrollWidth":1280,"innerWidth":1280,"pageHeight":2140,"consoleErrors":0,"errors":[...],"out":"..."}`。HTTP 不是 200 或 consoleErrors > 0 時結束碼 2(仍產生截圖) |
| `scope.sh` | `scope.sh snapshot <name>`;`scope.sh check <name> [<可寫路徑>...]`(可給零個路徑:任何變動都算 OUT,給驗證者用) | snapshot:記錄 `git status --porcelain -uall` 每個項目與其內容雜湊。check:重新計算,列出相對基準**新增、內容改變、或消失**(被刪除或被還原回 HEAD)的項目;落在可寫路徑外的印 `OUT <路徑>`(消失的印 `OUT-DEL`),範圍內印 `IN` / `IN-DEL`,最後 `out=<數量>`;out > 0 時結束碼 1。可忽略清單:`.next/`、`node_modules/`、`<tmp>` 內的檔案。只能判斷「這個 checkout 裡的變動」,所以平行的寫入 agent 必須各自在獨立 worktree |
| `secret-scan.sh` | `secret-scan.sh <name>` | 只掃 `scope.sh check` 列為 IN 的檔案(被 `.gitignore` 排除的檔案如 `.env.local` 不在 `git status` 內,不掃;它們本來就不會被 commit);規則:`NEXT_PUBLIC_[A-Z_]*(SECRET|KEY|TOKEN|PASSWORD)`、`(?i)(secret|password|passwd|api[_-]?key|token|private[_-]?key)\s*[:=]\s*["'][^"']{8,}["']`、`-----BEGIN [A-Z ]*PRIVATE KEY-----`、`sk-[A-Za-z0-9]{20,}`、`AKIA[0-9A-Z]{16}`;排除 `*_test.go`、`*.test.ts(x)`、`.env.example`、`dev`/`test`/`example`/`changeme` 開頭的值。印命中行(值以 `***` 遮蔽)與 `hits=<數量>`,hits > 0 時結束碼 1 |
| `proxy-diff.mjs` | `node proxy-diff.mjs <前端url> <後端url> <方法> <路徑> [--data <json>] [--cookie-jar <檔>(唯讀,curl `-c` 產生的 Netscape 格式;`#HttpOnly_` 開頭的行去掉前綴後當 cookie,其他 `#` 開頭的行才是註解;兩邊都帶)] [--ignore <欄位路徑>]... [--structure]` | 只用 Node 內建 `fetch`。同一請求打兩邊;`--data` 中的 `{uniq}` 在兩邊各換成不同的唯一值(時間戳 + 亂數)。預設比對狀態碼與 body(JSON 時忽略 `--ignore` 欄位,例如 `id`、`createdAt`、`items[].id`);`--structure` 時只比對狀態碼與 JSON 結構(鍵的集合與型別),用於非冪等端點。stdout 一行 JSON:`{"front":201,"back":201,"same":true,"mode":"structure","diff":[]}`;不一致時結束碼 1 |
| `concurrency.mjs` | `node concurrency.mjs <url> <方法> <路徑> [-n 10] [--data <json>] [--cookie-jar <檔>] [--expect 200,201]` | 只用 Node 內建 `fetch`。同時送 N 個(2–100)相同請求,`{uniq}` 每個請求各換成不同唯一值;stdout 一行 JSON `{"n":10,"statuses":{"200":10},"errors":0,"ok":true}`,不通過時附 5xx 回應樣本。預設通過條件:沒有 5xx 也沒有連線錯誤;給 `--expect` 時全部狀態碼都要在清單內。不通過結束碼 1(使用者 2026-11-16 要求整合驗證固定檢查並發) |
| `pg.sh` | `pg.sh up <專案名>`;`pg.sh down <專案名>`;`pg.sh schema <專案名> <表>` | 容器名 `dev-<專案名>-pg`,映像 `postgres:17`,帳密 `dev` / `devpass`,資料庫 `app`,埠從 5432 往上找可用埠並綁 `127.0.0.1`。已存在就 `docker start`,否則 `docker run -d`;等到 `pg_isready`。up stdout:`DATABASE_URL=postgres://dev:devpass@127.0.0.1:<埠>/app?sslmode=disable`。down:只 `docker stop`,不刪容器與資料。schema:`docker exec … psql -c '\d <表>'` 印出欄位。Docker 沒開:結束碼 3 |

## 測試
`tests/run.sh`:用 `python3 -m http.server` 測 serve / stop(含埠被占用改用下一個、提早結束、程序群組內子程序也被停掉)、serve(同名服務已執行時拒絕)、scope(基準前已修改的檔案再修改要被偵測、範圍外新增檔案列 OUT、刪除與還原列 IN-DEL / OUT-DEL)、secret-scan(命中與排除各一)。proxy-diff(用兩個小型 node 測試伺服器模擬相同 / 不同回應,並驗證 `{uniq}` 兩邊不同、`--structure` 只比結構)、cookie-jar 解析(含 `#HttpOnly_` 行的測試檔,`shot.mjs` 與 `proxy-diff.mjs` 都要讀到該 cookie)。`shot.mjs`、`proxy-diff.mjs`、`pg.sh` 在有 node / docker 時才測,沒有時印 `skip` 而不是通過。
